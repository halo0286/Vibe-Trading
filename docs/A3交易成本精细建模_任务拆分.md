## T1：PartialFillSchedule 数据模型（0.5d）

### 目标
定义部分成交的数据结构，不含业务逻辑，纯数据容器。

### 交付物
- `agent/backtest/engines/partial_fill.py`：`PartialFillSchedule` dataclass
- `agent/tests/test_partial_fill_model.py`：构造/属性/序列化测试

### 验收标准
- [ ] `PartialFillSchedule` 包含 total_shares, fill_schedule, fill_prices, unfilled_shares, participation_rates
- [ ] `avg_fill_price` / `total_cost` 属性正确计算
- [ ] frozen dataclass，不可变
- [ ] py_compile + pytest pass

### 代码骨架
```python
@dataclass(frozen=True)
class PartialFillSchedule:
    total_shares: float
    fill_schedule: np.ndarray      # shape=(n_bars,), shares per bar
    fill_prices: np.ndarray        # shape=(n_bars,), price per bar
    unfilled_shares: float
    
    @property
    def filled_shares(self) -> float:
        return float(np.sum(self.fill_schedule))
    
    @property
    def avg_fill_price(self) -> float:
        if self.filled_shares == 0:
            return 0.0
        return float(np.average(self.fill_prices, weights=self.fill_schedule))
    
    @property
    def total_cost(self) -> float:
        return float(np.sum(self.fill_schedule * self.fill_prices))
    
    @property
    def n_bars(self) -> int:
        return len(self.fill_schedule)
```

## T2：build_partial_fill_schedule 核心算法（1d）

### 目标
实现参与率约束下的渐进成交调度算法。

### 依赖
T1

### 交付物
- `partial_fill.py` 新增 `build_partial_fill_schedule()`
- `test_partial_fill_model.py` 新增算法测试

### 验收标准
- [ ] 每根 bar 成交量 ≤ ADV × max_participation
- [ ] 总成交量 ≤ total_shares
- [ ] max_bars 耗尽后停止，剩余记入 unfilled_shares
- [ ] 成交价含冲击（调用 impact_fn）
- [ ] ADV=0 → 全部 unfilled
- [ ] target=0 → 空 schedule
- [ ] max_bars=1 → 单 bar 尽力成交

### 函数签名
```python
def build_partial_fill_schedule(
    total_shares: float,
    price: float,
    adv_per_bar: float,
    direction: int,               # +1 buy, -1 sell
    max_participation: float = 0.1,
    max_bars: int = 5,
    impact_fn: Callable[..., float] = sqrt_impact,
    volatility: float | None = None,
    impact_coefficient: float = 0.5,
) -> PartialFillSchedule:
```
